p2p-battle 信令服务检测（Java HTTP + 信令接口 + WebSocket）

独立检测页，与游戏前端 HTML 无关。检测对象：APK 内置信令服务（NanoHTTPD + NanoWSD）。
判定口径
① GET /health 返回 {"ok":true} → 服务进程与 HTTP 层存活
② POST /create 返回 token → 信令房间/令牌接口可用
③ /ws 升级成功并收到 {"type":"joined"} → WebSocket 与信令会话正常
④ 成员端接入后房主端收到 members 广播 → 信令转发真的在工作

两点说明
· 跨源 POST 已使用 Content-Type: text/plain 规避浏览器 OPTIONS 预检，服务端按 Content-Length 读取正文，解析不受影响。
· 服务端存在约 5 秒空闲读超时（NanoWSD SO_TIMEOUT），静默连接可能被服务端主动关闭；只要握手成功且拿到 joined 帧，即判定 WebSocket 与信令正常，之后被关闭属空闲策略而非故障。
